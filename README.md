# CyberGuardian AI — Unified Platform

CyberGuardian AI is a unified React + TypeScript + Tailwind CSS security dashboard, authentication hub, and cybersecurity training platform.

---

## 🚀 Quick Start (Running on Any Laptop)

Follow these steps when running this project on a new laptop:

### 1. Requirements
- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher

### 2. Installation
Open your terminal inside the `CyberGuardian-AI` directory and run:
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for Production
```bash
npm run build
```

## 📦 How to Share Source Code with Others

When sharing this project (via ZIP file, USB drive, or Email/Drive):

1. **DO NOT include `node_modules` or `dist`** in the ZIP file.
   - Including `node_modules` causes platform mismatch errors when moving between Linux, Windows, or macOS.
2. **Compress only the source code files**:
   - `src/`
   - `public/`
   - `package.json` & `package-lock.json`
   - `vite.config.ts`, `tailwind.config.js`, `tsconfig.json`, etc.
3. On the destination laptop, extract the files, open a terminal in the folder, and run:
   ```bash
   npm install
   npm run dev
   ```
