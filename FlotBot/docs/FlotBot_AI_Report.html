🤖 What Is FlotBot AI?
FlotBot is an AI-powered desktop security monitoring tool that runs 24/7 on your machine. It combines two AI engines — one cloud (Gemini) and one local (Ollama) — to monitor your system in real-time, detect threats automatically, explain alerts in plain English, and guide you through security decisions. It works even without internet using local AI models.
🧠 AI Models Used
ModelProviderWhere It RunsUsed ForInternet?Status
Gemini 2.0 Flash Google DeepMind ☁️ Google Cloud Chat conversations, alert explanations, security questions ✅ Required Cloud AI
Llama 3.1 / Mistral Ollama (Local) 💻 Your Machine Threat analysis, background scanning, privacy-mode chat ❌ Not needed Local AI
MockProvider Built-in FlotBot 💻 Your Machine Offline keyword fallback when both providers are unavailable ❌ Not needed Fallback

⚡ Smart Auto-Selection: FlotBot automatically picks the best available model. If no Gemini API key is set, it silently switches to Ollama. If Ollama is offline, MockProvider takes over. The app never crashes regardless of provider state.

✅ What The AI Can Do

🔍 Explain Security Alerts

When a threat is detected, click "🔍 Explain" and the AI explains it in plain English using everyday analogies — no technical jargon.

  • 3-sentence beginner-friendly explanation
  • Tells you exactly what to do
  • Results cached for instant repeat access
  • Streams word-by-word (ChatGPT-style)

💬 Real-Time Laptop & Security Analysis

Ask FlotBot anything about your laptop, OS, specs, or security in natural language.

  • "What OS am I using and is my laptop safe?"
  • "What security tools and firewall do I have?"
  • "Check my CPU, RAM, and running processes"
  • "What apps are open on my machine?"
  • Real-time OS, kernel, firewall & RAM telemetry

📊 Threat Analysis Engine

Runs automatically every 5 seconds in the background. Uses Ollama to analyze all active alerts.

  • Generates a 0–100 threat score
  • Summarizes the threat landscape
  • Provides top 3 recommended actions
  • Only fires when alert state changes (efficient)

🛡️ Real-Time Alert Detection

Rule-based engine + AI augmentation detects threats before you notice them.

  • Suspicious process execution (PowerShell, cmd)
  • Network beaconing and C2 communication
  • File system mass modification (ransomware)
  • Persistence in autostart / cron / services

⚡ Streaming Responses

AI responses appear word-by-word in real-time — no waiting for the full reply.

  • Tokens pushed via IPC events
  • Blinking cursor shows active generation
  • Abort old request when new one sent
  • Cache replays instantly for repeat queries

🔒 Emergency Actions (UI Buttons)

High-impact security actions are performed via dedicated buttons — never via chat text (for safety).

  • 🚫 Terminate Process by PID
  • 🔒 Block IP via firewall
  • ✅ Dismiss Alert after review
  • ⚙️ Admin Console (whitelist / privacy toggle)

🔐 Privacy Modes & AI Behaviour

🟢 Online Mode (Default)

  • Chat: Gemini 2.0 Flash (cloud)
  • Analysis: Ollama (local, always)
  • Requires: GEMINI_API_KEY in .env
  • Best response quality for chat
  • Threat data never leaves machine

🔒 Privacy Mode (Admin Toggle)

  • Chat: Ollama (fully local)
  • Analysis: Ollama (fully local)
  • Zero cloud data — 100% offline
  • Toggle from Admin Console → no restart
  • Setting persists across app restarts

⚡ Auto-Fallback Mode

  • No Gemini key → auto-uses Ollama for chat
  • Ollama offline → uses MockProvider
  • App never crashes, always responds
  • Status badge shows current mode in UI
  • Latency pill shows response time (ms)
📈 AI Performance Improvements (v2.0)
  • Streaming tokens: First word appears in ~300ms — feels instant vs waiting 3–8s for full reply
  • Response caching: Repeated alert explanations served instantly from 2-min cache
  • Abort control: Sending a new message cancels the previous in-flight request immediately
  • Warm-up ping: Ollama model pre-loaded on startup — first real query has no cold-start delay
  • Parallel init: Both providers initialize simultaneously — startup is faster
  • Smart debounce: Background threat analysis only fires when alert state actually changes
  • Auto model selection: If configured model not installed, picks best available (qwen2.5, llama3, etc.)
  • Adaptive timeouts: Short chat = 12s timeout · Heavy analysis = 40s timeout
🚀 Quick Setup Guide

Step 1 — Prerequisites

  • Node.js v18+ installed
  • Ollama installed (ollama.com)
  • Run: ollama pull llama3.1
  • Or use existing: qwen2.5:3b

Step 2 — Configure

  • Copy .env.example → .env
  • Add GEMINI_API_KEY=... (optional)
  • Get key free at aistudio.google.com
  • Without key: Ollama handles everything

Step 3 — Run

  • Open terminal in project folder
  • Run: npm start
  • Floating shield bubble appears
  • Click bubble → chat panel opens
